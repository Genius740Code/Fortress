# Fortress is Now Open Source!

## https://github.com/Genius740Code/Fortress

### Please Star & Contribute!

**Fortress = SQLite simplicity + HashiCorp Vault security**

**Automatic Encryption** - Your data is encrypted automatically, no code changes needed
**Blazing Fast** - 1500+ MB/s with AEGIS-256 encryption  
**Multi-Tenant Ready** - Complete data isolation for SaaS apps
**Plugin System** - Extend functionality with WebAssembly
**Deploy Anywhere** - Docker, Kubernetes, bare metal

### Quick Start
```bash
cargo install fortress-cli
fortress create --name myapp --template enterprise
fortress start --port 8080
```
