# Fortress Plugin Development Guide

This guide provides **end-to-end instructions** for creating working WebAssembly plugins for Fortress.

## 🚀 Quick Start: Working Example

We provide a complete, working plugin example that you can build and install **right now**:

```bash

cd examples/simple-wasm-plugin

# Build the plugin (creates .fplugin package)
./build.sh

# Install with Fortress
fortress plugin install simple-wasm-plugin-0.1.0.fplugin
```

This example is **not aspirational** - it's a fully functional plugin that:

## 📝 Creating Your First Plugin

### Step 1: Set Up Project

```bash
# Copy the working example
cp -r examples/simple-wasm-plugin examples/my-plugin
cd examples/my-plugin

# Or create from scratch
cargo new --lib my-plugin
cd my-plugin
```

### Step 2: Configure Cargo.toml

```toml
[package]
name = "my-fortress-plugin"
version = "0.1.0"
edition = "2021"
license = "MIT"

[lib]
crate-type = ["cdylib"]

[dependencies]
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"
chrono = { version = "0.4", features = ["serde"] }

[profile.release]
opt-level = "s"
lto = true
```

### Step 3: Implement Plugin

```rust
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

// Plugin metadata
#[no_mangle]
pub static PLUGIN_METADATA: &str = r#"{
  "name": "my-fortress-plugin",
  "version": "0.1.0",
  "description": "My custom Fortress plugin",
  "author": "Your Name",
  "license": "MIT",
  "capabilities": ["custom_processing"],
  "entry_point": "my_function"
}"#;

// Plugin state
pub struct MyPlugin {
    request_count: u64,
}

impl MyPlugin {
    pub fn new() -> Self {
        Self {
            request_count: 0,
        }
    }
}

// Request/Response structures
#[derive(Debug, Serialize, Deserialize)]
pub struct MyRequest {
    pub data: String,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct MyResponse {
    pub result: String,
    pub processed_at: String,
}

// Plugin lifecycle
#[no_mangle]
pub extern "C" fn create_plugin() -> *mut MyPlugin {
    let plugin = Box::new(MyPlugin::new());
    Box::into_raw(plugin)
}

#[no_mangle]
pub extern "C" fn destroy_plugin(plugin: *mut MyPlugin) {
    if !plugin.is_null() {
        unsafe {
            let _ = Box::from_raw(plugin);
        }
    }
}

// Main plugin function
#[no_mangle]
pub extern "C" fn my_function(
    plugin: *mut MyPlugin,
    request_ptr: *const u8,
    request_len: usize,
) -> *mut u8 {
    if plugin.is_null() || request_ptr.is_null() {
        return std::ptr::null_mut();
    }

    // Update state
    let plugin = unsafe { &mut *plugin };
    plugin.request_count += 1;

    // Parse request
    let request_bytes = unsafe {
        std::slice::from_raw_parts(request_ptr, request_len)
    };
    
    let request: MyRequest = match serde_json::from_slice(request_bytes) {
        Ok(req) => req,
        Err(_) => {
            return create_error_response("Invalid request format");
        }
    };

    // Process data
    let result = format!("Processed: {}", request.data);
    
    // Create response
    let response = MyResponse {
        result,
        processed_at: chrono::Utc::now().to_rfc3339(),
    };

    // Return response
    let response_bytes = serde_json::to_vec(&response).unwrap_or_default();
    let ptr = response_bytes.as_ptr();
    std::mem::forget(response_bytes);
    ptr as *mut u8
}

// Helper function for error responses
fn create_error_response(message: &str) -> *mut u8 {
    let error_response = MyResponse {
        result: format!("Error: {}", message),
        processed_at: chrono::Utc::now().to_rfc3339(),
    };
    
    let response_bytes = serde_json::to_vec(&error_response).unwrap_or_default();
    let ptr = response_bytes.as_ptr();
    std::mem::forget(response_bytes);
    ptr as *mut u8
}

// Memory management
#[no_mangle]
pub extern "C" fn free_memory(ptr: *mut u8, len: usize) {
    if !ptr.is_null() {
        unsafe {
            let _ = Vec::from_raw_parts(ptr, len, len);
        }
    }
}
```

### Step 4: Build and Package

```bash
# Make build script executable
chmod +x build.sh

# Build for WebAssembly
./build.sh
```

This creates `my-fortress-plugin-0.1.0.fplugin` - a complete plugin package.

### Step 5: Install and Test

```bash
# Install the plugin
fortress plugin install my-fortress-plugin-0.1.0.fplugin

# List installed plugins
fortress plugin list

# Test the plugin (if you have Fortress running)
fortress plugin execute my-fortress-plugin --data '{"data":"test"}'
```

```rust
fn safe_process_request(request: &[u8]) -> Result<MyResponse, String> {
    let request: MyRequest = serde_json::from_slice(request)
```

## 🔒 Security Considerations

### WebAssembly Sandboxing

- ✅ **Memory Isolation**: Plugins run in isolated memory space
- ✅ **Capability Limits**: Plugins can only access allowed host functions
- ✅ **Resource Limits**: Memory and CPU usage can be constrained
- ✅ **No Direct System Access**: Plugins cannot directly access files or network

### Best Practices

1. **Validate All Inputs**:
   ```rust
   if request.len() > MAX_INPUT_SIZE {
       return error_response("Input too large");
   }
   ```

2. **Use Safe APIs**:
   ```rust
   // Use Fortress host functions instead of direct system calls
   let timestamp = fortress_host_get_timestamp();
   ```

3. **Handle Errors Gracefully**:
   ```rust
   match risky_operation() {
       Ok(result) => success_response(result),
       Err(e) => error_response(&format!("Operation failed: {}", e)),
   }
   ```

4. **Resource Management**:
   ```rust
   // Always free allocated memory
   #[no_mangle]
   pub extern "C" fn free_memory(ptr: *mut u8, len: usize) {
       if !ptr.is_null() {
           unsafe { let _ = Vec::from_raw_parts(ptr, len, len); }
       }
   }
   ```

## 🧪 Testing

### Unit Tests

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_plugin_creation() {
        let plugin = MyPlugin::new();
        assert_eq!(plugin.request_count, 0);
    }

    #[test]
    fn test_request_processing() {
        let request = MyRequest {
            data: "test".to_string(),
        };
        
        let json = serde_json::to_string(&request).unwrap();
        let parsed: MyRequest = serde_json::from_str(&json).unwrap();
        
        assert_eq!(parsed.data, "test");
    }
}
```

## 📦 Distribution

### Plugin Package Format

Fortress plugins use `.fplugin` extension (tar.gz format):

```

├── plugin.wasm          # Compiled WebAssembly binary
├── metadata.json        # Plugin metadata
├── config.json         # Default configuration (optional)
└── README.md           # Documentation
```
