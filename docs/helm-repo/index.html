Quick Installation

Add the repository and install Fortress in seconds

# Add the Fortress Helm repository
helm repo add fortress https://helm.fortress-db.com/charts
helm repo update

# Install Fortress
helm install my-fortress fortress/fortress \
  --namespace fortress \
  --create-namespace

# Check the installation
kubectl get pods -n fortress
